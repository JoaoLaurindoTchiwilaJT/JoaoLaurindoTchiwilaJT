🎯 **O que eu entrego:**

- ⚡ **Aplicações web modernas** com React, Node.js e Laravel
- 🔌 **APIs REST** bem estruturadas, seguras (JWT) e prontas para escalar
- 🖥️ **Sistemas desktop** robustos em Java + JavaFX
- 🗄️ **Bases de dados** otimizadas em MySQL

💡 **O que me move:** aprender todos os dias, escrever código legível e entregar soluções que realmente mudam a vida de quem as usa.
